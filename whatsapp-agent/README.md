# 🤖 סוכן וואטסאפ לאוריגמי CRM

סוכן חכם שמקבל הודעות בוואטסאפ בעברית, מבין אותן, ומבצע פעולות במערכת **אוריגמי CRM** —
דרך **n8n**. בנוי על מודל Claude.

## מה הסוכן יודע לעשות

| כותב לו בוואטסאפ | מה קורה |
|---|---|
| "תוסיף הוצאה $50 לספק משה כהן, פרויקט יעקב הלבן, סמן החזר לבנימין" | יוצר רשומת הוצאה באוריגמי עם כל השדות |
| "כמה שילמנו למשה כהן?" | מחפש ומחזיר את התשלומים |
| *(שולח תמונת חשבונית)* | קורא את החשבונית, מוצא את התשלומים התואמים לאותו ספק, ומסמן שיש עליהם חשבונית |

---

## 🛠️ איך מתקינים (5 שלבים)

### שלב 1 — לייבא את ה-Workflow
1. פותחים את n8n.
2. למעלה מימין: **⋯ → Import from File**.
3. בוחרים את הקובץ `origami-whatsapp-agent.n8n.json` מהתיקייה הזו.

### שלב 2 — לחבר את Claude (Anthropic)
1. לוחצים על הצומת **"מודל Claude"** ואז על **"קריאת החשבונית (ראייה)"**.
2. תחת *Credential* → **Create New** → מדביקים מפתח Anthropic API
   (מקבלים בכתובת https://console.anthropic.com).

### שלב 3 — לחבר את וואטסאפ
1. לוחצים על הצומת **"וואטסאפ - הודעה נכנסת"**.
2. מחברים את חשבון הוואטסאפ שלך (אותו חיבור שכבר יש לך ב-n8n).
3. עושים אותו דבר בצומת **"וואטסאפ - שליחת תשובה"** (אותו Credential).

### שלב 4 — לחבר את אוריגמי ⬅️ **החלק שדורש פרטים מאוריגמי**
צריך שני דברים מאוריגמי (ראה למטה איך להשיג):
- **כתובת ה-API** (Base URL)
- **מפתח API** (API Key)

מגדירים אותם ב-n8n כמשתני סביבה (**Settings → Variables** או קובץ `.env`):
```
ORIGAMI_BASE_URL=https://... (הכתובת שאוריגמי נותנים לך)
ORIGAMI_API_KEY=... (המפתח שאוריגמי נותנים לך)
```
בנוסף, בשלושת הכלים (`create_expense`, `find_payments`, `mark_invoice`) צריך
להתאים את **שמות השדות** (למשל `amount`, `supplier`, `project`) לשמות המדויקים
שאוריגמי משתמשים בהם. זה לוקח 5 דקות ברגע שיש תיעוד.

### שלב 5 — להפעיל
מעבירים את ה-Workflow ל-**Active** (מתג למעלה). זהו — שולחים הודעה בוואטסאפ ובודקים. ✅

## 📩 מה לשלוח לתמיכה של אוריגמי כדי לקבל את פרטי ה-API

העתק־הדבק את הטקסט הזה לתמיכה של אוריגמי:

> שלום, אני מחבר את המערכת שלי ל-n8n דרך ה-API של אוריגמי.
> אשמח לקבל:
> 1. את כתובת ה-API (Base URL) ומפתח API (API Key) לחשבון שלי.
> 2. תיעוד של הפעולות הבאות (Endpoints, שדות, ופורמט):
>    - יצירת הוצאה לספק (סכום, מטבע, ספק, פרויקט, החזר, הערות)
>    - חיפוש/שליפת תשלומים לספק
>    - עדכון תשלום לסימון "התקבלה חשבונית"

ברגע שתקבל את התיעוד — שלח לי אותו ואשלים את החיבור המדויק (שמות השדות והכתובות),
כדי שהסוכן יעבוד מקצה לקצה.

## הערות

- **מדוע קובץ ולא שינוי באפליקציה?** סוכן n8n חי בתוך n8n עצמו, לא בקוד אפליקציית
  התמלול. הקובץ כאן הוא ה"מתכון" של הסוכן שמייבאים ל-n8n.
- כרגע הכתובות והשדות של אוריגמי הם **מקומות שמורים (placeholders)** — הם מסומנים
  בבירור ומחכים להשלמה עם התיעוד האמיתי.
- אפשר להרחיב בקלות בעתיד: להוסיף עוד כלים (יצירת לקוח, פתיחת פרויקט, דוחות) —
  כל אחד הוא צומת כלי נוסף שמתחבר לסוכן.
