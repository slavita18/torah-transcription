# 🤖 סוכן וואטסאפ לאוריגמי CRM

סוכן חכם שמקבל הודעות בוואטסאפ בעברית, מבין אותן, ומבצע פעולות אמיתיות במערכת
**אוריגמי CRM** (`slavitapublishing.origami.ms`) — דרך **n8n**. בנוי על מודל Claude.

## מה הסוכן יודע לעשות

יש לו **4 כלים כלליים** שמכסים כל פעולה באוריגמי:

| כלי | מה הוא עושה |
|---|---|
| `origami_create` | יוצר רשומה חדשה — דיווח עבודה/הוצאה, משימה, לקוח... |
| `origami_query` | מחפש ושולף רשומות (עם המזהה) |
| `origami_update` | מעדכן רשומה — סימון "שולם", "קבלה", עדכון סטטוס משימה |
| `origami_delete` | מוחק רשומה (אחרי אישור) |

דוגמאות למה שאפשר לכתוב לו בוואטסאפ:

| כותב לו | מה קורה |
|---|---|
| "תוסיף הוצאה $50 לספק משה כהן, פרויקט יעקב הלבן, סמן החזר לבנימין" | יוצר רשומת **דיווח עבודה** עם כל השדות |
| "סמן ששילמתי לספק דוד לוי 1200 ₪" | מוצא את הרשומה ומעדכן **שולם=כן** |
| "תפתח משימה: להתקשר למדפיס עד יום ה'" | פותח **משימה** חדשה |
| "עדכן שהמשימה של העימוד הושלמה" | מעדכן סטטוס משימה |
| "תמחק את ההוצאה הכפולה של אתמול" | מאתר, מוודא, ומוחק |
| *(שולח תמונת חשבונית)* | קורא אותה, מוצא דיווחי עבודה תואמים ומסמן **קבלה=כן** |

### ☀️ בדיקה יומית אוטומטית
כל בוקר ב-**08:00** הסוכן שולף את המשימות הפתוחות ושולח לך אותן בוואטסאפ ושואל מה
לעשות. אתה עונה בחופשיות ("סגור 1 ו-3, דחה את 2 למחר") והוא מעדכן את המשימות בהתאם.
(אפשר לשנות את השעה בצומת **⏰ כל בוקר ב-08:00**.)

## 🗂️ מודל הנתונים האמיתי שלך (מתוך אוריגמי)

הסוכן מכיר את הישויות והשדות האמיתיים של החשבון שלך:

- **דיווחי עבודה** (הישות המרכזית לתשלומים/הוצאות לספקים) — שדות:
  `שם הספק`, `שם הפרויקט`, `מספר פרויקט`, `משימה`, `חודש`, `סכום`, `מטבע` (ש"ח/דולר),
  `שער הדולר`, `סכום בדולר`, `צורת תשלום`, `תאריך תשלום`, `אסמכתא`, `הוצאה להחזר`,
  `החזר לשמואל/בנימין`, `מאושר לתשלום`, `שולם`, `קבלה`, `מחיר לשעה`, `שעות`, `הערות`.
- **ספקים** — `שם`, `תפקיד`, `מחיר לשעה`, `כתובת מייל`, `טלפון נייד`, `טלפון נוסף`.
- **פרויקטים** — `מספר פרויקט`, `כותרת הפרויקט`, `סוג פרויקט`, `לקוח`, `מצב פרויקט`,
  `ניהול פרויקט`, `תאריך התחלה`, `תאריך סיום משוער`, `סה"כ לתשלום`.
- **משימות** — `כותרת`, `סטטוס`, `תאריך יעד`, `אחראי`, `פרויקט`.
- **לידים**, **לקוחות**, **אנשי קשר**, **עסקאות**, **תשלומים** — לפי הצורך.

## 🛠️ התקנה (5 שלבים)

### שלב 1 — לייבא את ה-Workflow
n8n → **⋯ → Import from File** → בוחרים את `origami-whatsapp-agent.n8n.json`.

### שלב 2 — לחבר את Claude (Anthropic)
בצמתים **"מודל Claude"** ו-**"קריאת החשבונית (ראייה)"**: *Credential → Create New* →
מדביקים מפתח Anthropic API (מ-https://console.anthropic.com).

### שלב 3 — לחבר את וואטסאפ
בכל צומתי הוואטסאפ (**הודעה נכנסת**, **שליחת תשובה**, **שליחת סיכום בוקר**) —
בוחרים את חיבור הוואטסאפ שכבר יש לך ב-n8n.

### שלב 4 — לחבר את אוריגמי (בעזרת החיבור שכבר יש לך!) ✅
בכל 5 הצמתים שפונים לאוריגמי (`origami_create`, `origami_query`, `origami_update`,
`origami_delete`, ו-"שליפת משימות פתוחות") — תחת *Credential* בוחרים את החיבור
הקיים שלך **"Origami API"** (Header Auth). זהו — הכתובת (`slavitapublishing.origami.ms`)
כבר מוגדרת בתוך הצמתים, ואין צורך להזין מפתח מחדש.

עוד שני משתנים קטנים (Settings → Variables) עבור סיכום הבוקר:
```
OWNER_PHONE=9725XXXXXXXX               # המספר שלך לקבלת סיכום הבוקר
WHATSAPP_PHONE_NUMBER_ID=<Phone Number ID מוואטסאפ>
```

### שלב 5 — בדיקה ויזואלית + הפעלה
1. פותחים את הצומת **`origami_query`** ולוחצים **Test step**.
2. אם חוזרות רשומות — מצוין. אם יש שגיאה — כנראה צריך להתאים את **פרמטר הישות**
   של ה-API (ראה למטה). מתקנים ולוחצים Test עד שעובד — הכל ויזואלי, בלי קוד.
3. מעבירים את ה-Workflow ל-**Active**. שולחים הודעה בוואטסאפ ובודקים. ✅

## ⚠️ הדבר האחד שנותר לאמת

בניתי את הכל מתוך **סרטון המסך ששלחת** — הכתובת, שמות הישויות והשדות כולם אמיתיים.
הדבר היחיד שאי אפשר לראות מסרטון הוא **הפורמט המדויק שבו ה-API של אוריגמי מזהה
ישות** (האם לפי השם בעברית "דיווחי עבודה", או לפי מזהה פנימי, ובאיזה פרמטר). כרגע
הכלים מעבירים את שם הישות בפרמטר `entity` — אם ה-API של אוריגמי מצפה למשהו אחר, זה
יתגלה מיד ב-**Test step**, וזה תיקון של שורה אחת.

> 💡 את הפורמט המדויק רואים במסך ה-API/אינטגרציות של אוריגמי (אותו מקום שבו הוגדר
> ה-Credential "Origami API"). אם תשלח לי צילום של מסך ה-API הזה, אנעל את זה סופית.
