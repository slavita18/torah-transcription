# 🤖 סוכן וואטסאפ לאוריגמי CRM

סוכן חכם שמקבל הודעות בוואטסאפ בעברית, מבין אותן, ומבצע פעולות אמיתיות במערכת
**אוריגמי CRM** (origami.ms) — דרך **n8n**. בנוי על מודל Claude.

## מה הסוכן יודע לעשות

יש לו **4 כלים כלליים** שמכסים כל פעולה באוריגמי:

| כלי | מה הוא עושה |
|---|---|
| `origami_create` | יוצר רשומה חדשה — הוצאה, משימה, לקוח, תשלום... |
| `origami_query` | מחפש ושולף רשומות (עם המזהה) |
| `origami_update` | מעדכן רשומה — סימון "שולם", עדכון סטטוס משימה, סימון "התקבלה חשבונית" |
| `origami_delete` | מוחק רשומה (אחרי אישור) |

דוגמאות למה שאפשר לכתוב לו בוואטסאפ:

| כותב לו | מה קורה |
|---|---|
| "תוסיף הוצאה $50 לספק משה כהן, פרויקט יעקב הלבן, סמן החזר לבנימין" | יוצר רשומת הוצאה |
| "סמן ששילמתי לספק דוד לוי 1200 ₪" | מוצא ומעדכן לסטטוס "שולם" |
| "תפתח משימה: להתקשר למדפיס עד יום ה'" | פותח משימה חדשה |
| "עדכן שהמשימה של העימוד הושלמה" | מעדכן סטטוס משימה |
| "תמחק את ההוצאה הכפולה של אתמול" | מאתר, מוודא, ומוחק |
| *(שולח תמונת חשבונית)* | קורא אותה, מוצא תשלומים תואמים ומסמן שיש חשבונית |

### ☀️ בדיקה יומית אוטומטית
כל בוקר ב-**08:00** הסוכן שולף את המשימות הפתוחות ושולח לך אותן בוואטסאפ ושואל מה
לעשות. אתה עונה בחופשיות ("סגור 1 ו-3, דחה את 2 למחר") והוא מעדכן את המשימות בהתאם.
(אפשר לשנות את השעה בצומת **⏰ כל בוקר ב-08:00**.)

## 🛠️ התקנה (6 שלבים)

### שלב 1 — לייבא את ה-Workflow
n8n → **⋯ → Import from File** → בוחרים את `origami-whatsapp-agent.n8n.json`.

### שלב 2 — לחבר את Claude (Anthropic)
בצמתים **"מודל Claude"** ו-**"קריאת החשבונית (ראייה)"**: *Credential → Create New* →
מדביקים מפתח Anthropic API (מ-https://console.anthropic.com).

### שלב 3 — לחבר את וואטסאפ
בכל צומתי הוואטסאפ (**הודעה נכנסת**, **שליחת תשובה**, **שליחת סיכום בוקר**) —
בוחרים את חיבור הוואטסאפ שכבר יש לך ב-n8n.

### שלב 4 — לחבר את אוריגמי (בעזרת החיבור שכבר יש לך!) ✅
בכל 5 הצמתים שפונים לאוריגמי (`origami_create`, `origami_query`, `origami_update`,
`origami_delete`, ו-"שליפת משימות פתוחות") — תחת *Credential* בוחרים את החיבור
הקיים שלך **"Origami API"** (Header Auth). זהו — אין צורך להזין מפתח מחדש, הוא כבר
מוגדר אצלך ב-n8n.

עוד משתנים קטנים (Settings → Variables, או `.env`):
```
ORIGAMI_BASE_URL=https://<שם-החשבון-שלך>.origami.ms   # הכתובת שאתה רואה כשאתה מחובר לאוריגמי
OWNER_PHONE=9725XXXXXXXX                              # המספר שלך לקבלת סיכום הבוקר
WHATSAPP_PHONE_NUMBER_ID=<ה-Phone Number ID מוואטסאפ>
```

### שלב 5 — לוודא שמות ישויות ושדות (בדיקה ויזואלית בתוך n8n)
הכלים בנויים על המבנה הרשמי של אוריגמי (`/entities/api/instance_data/...`), אבל
**שמות הישויות והשדות** הם לפי איך שבנית את החשבון שלך (בקוד רשמתי "הוצאות",
"משימות", "תשלומים" כברירת מחדל). כדי לוודא:
1. פותחים את הצומת **`origami_query`**, לוחצים **Test step**.
2. אם חוזרות רשומות — מצוין, השמות נכונים. אם יש שגיאה — מתקנים את שם הישות
   ולוחצים Test שוב, עד שעובד. הכל ויזואלי, בלי קוד.

**אם תשלח לי כאן דוגמת רשומה אחת מאוריגמי (או שם ישות + שמות שדות), אשלים לך את
השמות המדויקים בכלים.**

### שלב 6 — להפעיל
מעבירים ל-**Active**. שולחים הודעה בוואטסאפ ובודקים. ✅

## למה עדיין נשאר שלב אחד לא-אוטומטי?

אני לא יכול להיכנס לחשבון אוריגמי הפרטי שלך (אין לי גישה לחשבונות מחוברים של
משתמשים), והסביבה כאן גם חוסמת גישה ישירה לאתר של אוריגמי. לכן בניתי את הכל על
בסיס **מבנה ה-API הרשמי והמתועד** של אוריגמי — מה שחסר זה רק ההתאמה הסופית של שמות
הישויות/השדות שלך, וזה 5 דקות ברגע שרואים דוגמה אחת מהחשבון שלך.

> **טיפ:** לאוריגמי יש כבר **תוסף רשמי ל-Claude** עם 14 כלים. אם תרצה, זו גם דרך
> חלופית מהירה לחבר את Claude לאוריגמי — אבל היא לא עוברת דרך וואטסאפ. ה-Workflow
> כאן הוא הדרך לחבר את זה ל**וואטסאפ** דרך n8n, כפי שביקשת.
