# שפירא · הוצאת ספרים — אתר תדמית

אתר תדמית סטטי בעברית (RTL) לרענון המיתוג של Slavita Publishing לקהל הישראלי.

## מיתוג

- **שם חדש:** שפירא · הוצאת ספרים
  (על שם ר' משה שפירא, מייסד בית הדפוס בסלאוויטא ב־1791)
- **סלוגן:** מורשת של דיוק, עיצוב של זמננו
- **פלטה:** Midnight `#0F1B2D` · Cream `#F8F4EC` · Gold `#B89464`
- **טיפוגרפיה:** Frank Ruhl Libre (כותרות) + Heebo (טקסט)

## הפעלה מקומית

זהו אתר סטטי בלי תלות בכלי בנייה. הפעלה:

```bash
cd site
python3 -m http.server 8080
# פתיחה בדפדפן: http://localhost:8080
```

או כל שרת סטטי אחר (`npx serve`, Vercel, Netlify וכו').

## מבנה

```
site/
├── index.html      # עמוד יחיד עם כל הקטעים
├── style.css       # עיצוב מלא, RTL, רספונסיבי
├── script.js       # תפריט מובייל + reveal on scroll
├── favicon.svg     # סמליל
└── assets/         # שמור לקבצי מדיה נוספים
```

## קטעי האתר

1. Hero — הצהרת המיתוג + נתונים
2. על ההוצאה — סיפור המורשת מסלאוויטא
3. שירותים — שש משבצות שירות
4. קטלוג — שש סדרות לדוגמה (כריכות CSS)
5. תהליך העבודה — שישה שלבים
6. המלצות — שלוש עדויות
7. צרו קשר — פרטים + טופס שמפעיל `mailto:`

## פריסה

מתאים לפריסה ב־Vercel/Netlify כתיקיית `site/` סטטית. ב־Vercel ניתן להגדיר
את `outputDirectory: "site"` ולוודא ש־`Framework Preset = Other`.
