# פרדס התורה — Newsletter text replacement

Replaces the text of the **פרדס התורה** gilyon template (parshas **Shoftim**,
`source/template-shoftim.pdf`) with new content for parshas **Pinchas**
(`source/content-pinchas.docx`), keeping the original design, section names
(מדורים) and layout untouched.

## Result
`pardes-hatorah-pinchas.pdf` — two pages, generated by `build.py`.

## What is replaced vs. kept
**Replaced** (with the Word-document content):
- The masthead issue line (`פרשת פינחס תשפ"ו · גליון ? · שנה ? · …`)
- All four section bodies
- Three section topic-titles: `מעלת הייחוס`, `דין המועדות לעתיד לבוא`,
  `בענין היתר עשיית גורל` (the fourth, `פנינים ופרפראות`, is identical to the
  template so it is left as-is)

**Kept unchanged** (original artwork):
- Header banner / logo, decorative type-words (`א געדאנק`, `א שמועס`,
  `א הלכה`, `א חידוש`), column frames and rules
- The bottom "פטרון השבוע" dedication cards and the thank-you footer

## Section mapping (the מדורים)
| Template type-word | Topic title (Pinchas)      |
|--------------------|----------------------------|
| א געדאנק           | פנינים ופרפראות            |
| א שמועס            | מעלת הייחוס                |
| א הלכה             | דין המועדות לעתיד לבוא     |
| א חידוש            | בענין היתר עשיית גורל      |

## Notes
- The gilyon/shana numbers in the masthead show `?` because the Word document
  left them blank. Fill them in `source/content-pinchas.docx` (paragraph 2) and
  rebuild.
- Body text is auto-scaled per column so the (longer) new content fits the same
  two-page template.
- Fonts: **Frank Ruhl Libre** (SIL OFL) in `fonts/`, chosen to match the
  template's Frank Ruhl typeface.

## Rebuild
```bash
pip install pymupdf python-docx
python3 build.py
```
