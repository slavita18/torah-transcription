# פרדס התורה — Newsletter text replacement

Replaces the text of the **פרדס התורה** gilyon template (parshas **Shoftim**,
`source/template-shoftim.pdf`) with new content for parshas **Pinchas**
(`source/content-pinchas.docx`), keeping the original design, section names
(מדורים) and layout intact.

## Result
`pardes-hatorah-pinchas.pdf` — two pages, generated by `build.py`.

## Fonts — the template's real typefaces
The new text is set in the **actual fonts embedded in the template PDF**
(Frank Ruhl for the body, FbLoaHari for the masthead, BATzarfati for the topic
titles, EFTTefilot for "פטרון השבוע"), so it matches the original exactly.
The embedded subsets are Type0/Identity fonts with no Unicode `cmap`, so they
are recovered in two steps:

1. `reconstruct_fonts.py` — reads each font's `ToUnicode` map (CIDToGIDMap is
   Identity) and rebuilds a proper Unicode→glyph `cmap`, producing usable TTFs.
2. `complete_fonts.py` — fills the few glyphs a subset lacks (mostly
   punctuation) from Frank Ruhl Libre / the font's own other weight.

The resulting TTFs live in `fonts/`.

## What is replaced vs. kept
**Replaced** with the Word-document content:
- Masthead issue line — `פרשת פינחס תשפ"ו · גליון א' · שנה כ' · …`
- All four section bodies
- Three topic-titles: `מעלת הייחוס`, `דין המועדות לעתיד לבוא`,
  `בענין היתר עשיית גורל` (the fourth, `פנינים ופרפראות`, already matched the
  template and is left untouched)
- The bottom **"פטרון השבוע"** grid → **one enlarged dedication card** for the
  week's patron, **משה גרינפעלד** (full honorifics kept). The freed vertical
  space is used to **widen the א הלכה column** so it is less cramped.

**Kept unchanged** (original artwork):
- Header banner / logo, decorative type-words (`א געדאנק`, `א שמועס`,
  `א הלכה`, `א חידוש`), column frames and rules, thank-you footer, page footers.

## Section mapping (the מדורים)
| Template type-word | Topic title (Pinchas)      |
|--------------------|----------------------------|
| א געדאנק           | פנינים ופרפראות            |
| א שמועס            | מעלת הייחוס                |
| א הלכה             | דין המועדות לעתיד לבוא     |
| א חידוש            | בענין היתר עשיית גורל      |

## Editing
- Issue numbers and the patron name are constants at the top of `build.py`
  (`ISSUE`, `PATRON`).
- Body text is auto-scaled per column (uniform size, short columns vertically
  centered) so the longer new content fits the same two-page template.

## Rebuild
```bash
pip install pymupdf python-docx fonttools pikepdf
python3 reconstruct_fonts.py && python3 complete_fonts.py   # only to regenerate fonts/
python3 build.py
```
