# אוטומציית n8n – סיכום דיווחים לא משולמים (פרויקט "בעל שם טוב")

וורקפלואו ל-n8n ששולח **בכל 3 לחודש בשעה 08:00** מייל אל **מנחם ברקוביץ (סלאוויטא)**
עם טבלה מסודרת של כל הדיווחים בפרויקט **"בעל שם טוב"** מתוך מערכת **אוריגמי**,
ש**טרם אושרו לתשלום וטרם שולמו**.

קובץ הוורקפלואו: [`origami-baal-shem-tov-unpaid-reports.json`](./origami-baal-shem-tov-unpaid-reports.json)

## איך מייבאים ל-n8n

1. ב-n8n: **Workflows → ⋮ → Import from File** ובחרו את קובץ ה-JSON.
2. הגדירו את שני ה-Credentials (ראו למטה).
3. מלאו את הפרטים בצומת **"הגדרות"**.
4. הריצו **Test workflow** לבדיקה, ואז הפעילו (**Active**).

## מה צריך למלא (צומת "הגדרות")

| שדה | ערך | הערה |
|------|------|------|
| `recipientEmail` | כתובת המייל של מנחם ברקוביץ | **חובה למלא** – כרגע placeholder |
| `recipientName` | `מנחם ברקוביץ` | לשימוש בגוף המייל |
| `projectName` | `בעל שם טוב` | שם הפרויקט לסינון |
| `origamiBaseUrl` | כתובת ה-API של אוריגמי | עדכנו לפי חשבונכם |

## Credentials

1. **Origami API Header Auth** (סוג `Header Auth`) – בצומת "שליפת דיווחים מאוריגמי".
   הגדירו Header לפי דרישות ה-API של אוריגמי, לרוב:
   `Authorization` = `Bearer <TOKEN>`.
2. **Gmail account** (סוג `Gmail OAuth2`) – בצומת "שליחת מייל למנחם".
   ניתן להחליף בצומת **Send Email (SMTP)** אם עדיף לשלוח דרך שרת דואר של סלאוויטא.

## התאמה למבנה הנתונים של אוריגמי

הקוד בצומת **"סינון ובניית טבלה"** בנוי בצורה עמידה ומזהה אוטומטית מגוון שמות שדות
נפוצים (תאריך, מדווח, תיאור, שעות, סכום, סטטוס) וגם כמה צורות של "מאושר"/"שולם".
אם ב-API שלכם השדות בשמות אחרים – יש הערות בקוד (`pick()` וכן `isPaid` / `isApprovedForPayment`)
שמסבירות בדיוק היכן לעדכן.

- הסינון: נשמרים רק דיווחים ש**גם** לא אושרו לתשלום **וגם** לא שולמו.
- אם אין דיווחים ממתינים – עדיין נשלח מייל עם הודעת "אין דיווחים ממתינים".
- אזור זמן הוורקפלואו מוגדר `Asia/Jerusalem`.

## שינוי מועד/שעת השליחה

בצומת **"כל 3 לחודש (08:00)"** – ה-Cron הוא `0 8 3 * *`
(דקה 0, שעה 8, יום 3 בחודש). שנו לפי הצורך.
